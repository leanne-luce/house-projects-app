`Button` in all six Club Luce variants. Nothing in this system has a rounded corner, and no button ever carries a shadow.

```jsx
<Button variant="outline">Browse all plans</Button>
<Button variant="primary">Add to inbox</Button>
<Button variant="secondary">File…</Button>
<Button variant="link">View plan →</Button>
```

`outline` inverts to solid brown on hover — that inversion is the brand's one piece of interactive theatre. Use it for the main action on a marketing page. `primary` (filled terracotta) is for product UI, where an outline button would be too quiet.
